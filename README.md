# STYLE ME AI V2

1. Upload a reference image.
2. OpenAI vision analyzes it and creates an English production prompt.
3. Edit the prompt if desired.
4. Upload your personal image.
5. Seedream 4.5 receives both images plus the prompt.
6. Download the result.

Netlify environment variables:
- OPENAI_API_KEY
- REPLICATE_API_TOKEN

Never place API keys inside index.html or commit them to GitHub.
